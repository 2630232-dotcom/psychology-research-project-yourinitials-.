# Study Habits and Student Well-being

## Purpose
This fictional class project explores how study habits may relate to students' well-being. It helps organize ideas for a classroom activity about time management and healthy study routines.

## Files
- project_plan.docx — outlines the project activities.
- survey_draft.docx — contains sample questions for classroom discussion.
- data_dictionary.xlsx — explains example data fields.
